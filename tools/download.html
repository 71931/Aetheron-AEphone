装的时候

  1. 系统提示「未知来源」→ 允许安装，这是自签名包，属正常。
  2. 装完去「文件 / 下载记录」里能看到刚才下的 apk，点它安装即可。
  3. 打开 App 后，在设置页填「服务器地址」「Token」「设备 ID」三格，值在聊天里拿。

权限怎么给（不影响你手机）

  1. 想省事就先只给两个：「通知读取」+「使用情况访问」。这两个不是无障碍，只让 TA 知道你手机大概在干嘛（电量、当前 App、屏幕时间、通知）。
  2. 要截图、锁 App、息屏、替你点按钮：才需要开无障碍里的「掌心窗服务」。系统设置 → 无障碍 → 已下载的服务 → 掌心窗服务 → 开启。
  3. 想让 TA 弹提醒：加一个「悬浮窗」权限。
  4. 提示「受限设置 / 出于安全考虑不可用」：设置 → 应用 → 掌心窗 → 右上角「⋯」→ 允许受限设置，再回去开。
  5. 不想用了随时关：无障碍、通知、使用情况都能在系统设置里单独撤掉；卸载 App 就全部清空，不改你系统任何东西。
建议：先只给第 1 条试玩，觉得用得上了再开无障碍。
