小红书通道 · 三步接上

AEphone 站点用 · 照着念就行
先说清一件事：这条通道必须跑在一台电脑上（Windows / Mac / Linux 都行），而且是装了小红书 MCP、并且已经登录小红书的那台电脑。手机单独接不了——手机在这事里只负责最后一格：填地址。

第 1 步 · 在电脑上把脚本下载下来

用那台电脑的浏览器打开下面任一链接（自动下载，是纯文本脚本，不是安装包，不用装任何东西）：

Windows：start-bridge-windows.bat Mac / Linux：xhs_bridge.py

Mac 用户也可以顺手把 start-bridge-mac.command 一起存下来，放在同一文件夹。

下载地址（复制到电脑浏览器打开）：
https://71931.github.io/Aetheron-AEphone/tools/start-bridge-windows.bat
https://71931.github.io/Aetheron-AEphone/tools/xhs_bridge.py

第 2 步 · 让通道跑起来

Windows：存好的 start-bridge-windows.bat 直接双击。出现黑窗口别关，它就是个「转接头」。

Mac / Linux：把脚本存到桌面，打开「终端」，粘下面这一行回车（把路径换成实际位置）：

cd ~/Desktop && python3 xhs_bridge.py --tunnel --mcp http://localhost:18061/mcp --token aetheron

两种跑法都会印出一行地址，长这样：
https://xxxx-xxxx.trycloudflare.com
这就是「通道地址」，复制它。

第一次跑可能要等十几秒（在下载隧道小工具），耐心等一下。窗口关掉＝通道断开，下次要用就再双击一次。

第 3 步 · 回手机上填一格

手机站点里进：设置 → MCP → 小红书 → 「通道地址（手机读小红书靠它）」。

① 通道地址：粘上刚才那行 https 地址
② 令牌：aetheron（已经帮你填好了，别改）
③ 点「保存」→ 点「测连通」

看到「已连通：已登录：xxxx」就成了。之后在聊天里给被授权的小红书 Char 发一条笔记链接，它就能真读到标题、正文和评论区；说一句「给我发条小红书」，它也会真搜真分享。

常见报错对号入座

没通：连不上通道（Failed to fetch）

① 电脑上那个黑窗口是不是关了？关了就得重开。② 地址粘全了吗，末尾别多斜杠。③ 电脑和手机得能上网，隧道是走公网的，两边都不需要在同一 WiFi。

没通：令牌不对

令牌填 aetheron（跟启动命令里的 --token 一致）。改过命令里的令牌，这里就得填改后的那个。

没通：通道地址不对（404）

地址应当是 https://xxx.trycloudflare.com 这样的根地址，别自己加 /call 或 /mcp 后缀。

被浏览器拦了 / 提示混合内容

站点是 https，通道也必须是 https。用上面带 --tunnel 的命令跑，拿到的就是 https 地址；只填 http://192.168.x.x:18901 会被浏览器挡掉。

测连通是通的，但聊天里说「通道还没接上」

两种情况：① 这个 Char 没被授权——去「选择 Char 使用」里勾上它；② 那条链接是短链（xhslink.com），先让它在聊天里待一会儿，页面会自动把它展开再读，稍等或把长链接发过来。

Windows 双击一闪而过 / 提示没找到 python

这台电脑没装 Python。去 python.org 装 Python 3，安装第一条记得勾 Add python.exe to PATH，装完再双击一次。

Mac 双击提示没有执行权限

终端里跑一句 chmod +x start-bridge-mac.command（先把 cd 到文件所在文件夹），再双击。

它到底在转什么

小红书 MCP 本身不让网页直接调用（跨域 + 需要登录态）。这个小脚本在电脑上开一个中转口，把网页的请求转给 MCP，再把结果带回来；带 --tunnel 时还会顺手开一条临时 https 通道，让手机上的站点能安全地访问到它。脚本只在本机跑，不往外传你的小红书登录信息。
