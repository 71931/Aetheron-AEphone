掌心窗 · 三步接上

掌心窗公开版 = 安卓 App + 云端后端 server + 云端 MCP 三件套。
手机那个 App 负责看和动手，云端的 MCP 负责把这些能力开给 AI。一次弄好，以后开机即用。
一句话分工：手机端填 server 的地址，AI（站点里那个通道地址）填 mcp 的地址，两边的 Token 必须是同一个。

1云端起服务（一次性，约 5 分钟）

① 手机或电脑打开下面这个链接，用 GitHub 账号登录并授权，其余全默认，点部署：

https://render.com/deploy?repo=https://github.com/linzhi-524/linjian-peek-public

② 它会自动建两个服务：zhangxinchuang-server（手机连）和 zhangxinchuang-mcp（AI 连），并自动生成一个共享令牌 LINJIAN_TOKEN。

③ 部署完做两件事：

  • 打开 mcp 服务 → Environment，复制 LINJIAN_TOKEN 的值（后面要填两次）。
  • 记下两个域名：server 的公网地址、mcp 的公网地址（形如 https://xxxx.onrender.com）。

免费实例会休眠，第一次访问要等 30~60 秒冷启动，转圈别慌。

2手机装 App 并连上

① 装公开版 APK：仓库 Actions → Build Android Public APK → 跑一次工作流，下载产物里的 APK 安装。

https://github.com/linzhi-524/linjian-peek-public/actions

② 打开 App → 设置页填三样：

服务器地址server 的公网域名，不要结尾加斜杠
Token第 1 步复制的那串 LINJIAN_TOKEN
设备 IDandroid-phone

③ 去系统里把权限开齐：无障碍（掌心窗服务）、通知使用权、使用情况访问；再把电池优化关掉、允许后台运行，回 App 点启动。

如果系统提示「受限设置 / 出于安全考虑不可用」：设置 → 应用 → 掌心窗 → 右上角菜单 → 允许受限设置，再回无障碍里打开「掌心窗服务」。

3回到站点填 MCP 地址

站点 → MCP → 掌心窗 → 通道地址：

https://你的-mcp-域名/mcp

Token 填同一个 LINJIAN_TOKEN → 点「保存」→ 点「测连通」。看到 ok=true 和 linjian_status 的返回，就是通了。

然后点详情页顶部那一栏挑 Char：勾上的角色，聊天时就能看到并使用这台手机。

地址和 Token 只存在你这台手机的浏览器里（localStorage），不上传服务器、也不写进站点源码。

常见报错怎么对

连不上 / 超时Render 冷启动，等 30~60 秒再点一次；或确认地址结尾是 /mcp。
令牌不对 401站点、mcp 服务、手机 App 三处的 Token 必须是同一个 LINJIAN_TOKEN。
health 里 has_url=falsemcp 服务没拿到 server 地址：重新同步一次 Blueprint，或手动把 LINJIAN_URL 填成 server 公网地址后重新部署 mcp。
能连但读不到状态手机端 App 被系统杀了 / 无障碍掉了。把 App 拉回前台，确认服务是启动状态。
浏览器直接拒绝填的是 http 地址。站点是 https，浏览器不允许连 http（局域网自建除外）。云端部署天然是 https。
把 server 当成 mcpserver 只给手机用。AI 端必须填 mcp 服务的域名，且结尾加 /mcp。

规矩（别嫌啰嗦）

只连自己的手机、自己的服务。截图、读屏、点击、输入、门禁、息屏都是敏感能力；Token 别发给陌生客户端，也别拿掌心窗去管别人的设备。

删日记、删日记本这类不可逆动作，MCP 要求显式确认才会执行。
